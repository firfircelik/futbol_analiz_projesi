## 💻 Technical Architecture (Production)

```
┌─────────────────────────────────────────────────────────────┐
│                      USERS                                   │
│   Web App    │    Mobile App    │    API Clients           │
└───────┬──────────────┬──────────────────┬───────────────────┘
        │              │                  │
        └──────────────┴──────────────────┘
                       │
        ┌──────────────▼──────────────┐
        │   CloudFlare CDN + WAF      │
        └──────────────┬──────────────┘
                       │
        ┌──────────────▼──────────────┐
        │    Load Balancer (nginx)    │
        └──────────────┬──────────────┘
                       │
        ┌──────────────▼──────────────┐
        │   FastAPI App Servers       │
        │   (3+ instances)            │
        └──────────────┬──────────────┘
                       │
        ┌──────────────▼──────────────────────────────┐
        │  PostgreSQL (Primary + Read Replicas)       │
        │  Redis (Caching + Rate Limiting)            │
        │  S3/Object Storage (Reports, Images)        │
        └─────────────────────────────────────────────┘

Background Jobs:
- Data collection (hourly)
- Report generation (queue)
- Analytics calculation (daily)
- Email sending
```

## ⚖️ Legal & Compliance

### Data Usage

**What's Legal:**
✅ Using publicly available stats from official sources
✅ Calculating our own metrics (xG, Opta Index, etc.)
✅ Aggregating data from multiple public sources
✅ Offering analytics/insights as a service

**What's Risky:**
⚠️ Scraping some websites (check Terms of Service)
⚠️ Using player/team names (usually okay, but verify)
⚠️ Using league logos (require permission/licensing)

**Legal Structure:**
- LLC or Ltd Company
- Terms of Service
- Privacy Policy (GDPR compliant)
- Data Processing Agreement
- API Terms of Use

**Insurance:**
- Professional Indemnity Insurance
- Cyber Liability Insurance
